# Placement-Radiness-Tracker
Industry Readiness Programme-II CSE2596 Assignment
## Features
- Stores student aptitude, verbal, and coding scores.
- Validates scores between 0 and 100.
- Calculates student averages and grades.
- Identifies the top scorer and students needing practice.
- Finds the second-highest distinct score.

## Branching
Feature development is carried out in the feature-grades branch.
## How to Run

1. Open the project folder.
2. Run placement_tracker.py to view student records and grades.
3. Run runner_up.py to calculate the second-highest distinct score.

## Grade Criteria

- A: Average 80 or above
- B: Average 60 to 79
- C: Average 40 to 59
- Needs practice: Average below 40

## Testing

Both Python programs should be tested with valid inputs and boundary values.
